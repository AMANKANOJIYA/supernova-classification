🔭 Transient Supernova Classifier

connecting…

This system classifies transient astronomical alerts — sudden brightenings detected by sky surveys — into three supernova types (Ia, Ib/c, II) from their light curves alone, using a causal (no-future-peeking) neural encoder pretrained on 843,617 simulated LSST objects and fine-tuned on real ZTF supernovae with spectroscopic labels.

A second branch ranks every incoming alert for how unlike an ordinary supernova it looks, to surface rare or artifact-driven objects for human review. Everything below is read live from this project's own evaluation reports — nothing here is recomputed.

What this is

A supernova is a star that explodes, briefly outshining its entire host galaxy. Different progenitor physics produce different explosion types, and the definitive way to tell them apart is spectroscopy — splitting the light into a spectrum with a prism. Spectroscopy is precise but scarce: it needs a large telescope and dedicated time per object, while sky surveys detect millions of transients a night. What every survey does produce automatically is a light curve: brightness (calibrated flux, never plain magnitude — flux can be negative on a noisy non-detection, magnitude can't) measured over time in a few wavelength filters. This project asks how much of the spectroscopic answer can be recovered from a light curve's shape alone, early enough to tell a human "point a spectrograph at this one" — and, separately, which alerts don't look like any known supernova type at all and deserve a closer look.

The three supernova types

Type Ia

A white dwarf that detonates after accreting matter from a companion, or two white dwarfs merging. No hydrogen in the spectrum. Physically similar to each other, so their true brightness is predictable — the "standard candles" used to measure the universe's expansion.

Type Ib/c

A massive star that already blew off its outer hydrogen (and, for Ic, helium) envelope before core collapse. Ib and Ic are merged into one class here — separating them needs spectroscopy this pipeline doesn't have.

Type II

A massive star that still has its hydrogen envelope when it collapses. The most common type in the real sky, and the class this classifier is best at.

What's still unresolved GUIDE.md §9, full detail

  1. Tier B static-encoder inversion. Host/static features help on Tier A but make Tier B fine-tuning measurably worse (0.6716 LC-only vs. 0.6343 LC+static). The leading hypothesis (missing photo-z) was tested and refuted — only 33% of the Tier A gain traces to it. No alternative was isolated with its own ablation.
  2. Gate D's real question is still unasked. Every population built so far (Tier B "weird", live Fink ingestion) excludes bogus/artifact candidates by construction. Closing it needs an unfiltered Fink stream or reject/candidate topics.
  3. avro_lsst.py is unverified against real traffic. Every LSST topic returned zero currently-queued messages at both checks this project made, despite offsets in the hundreds of thousands proving real production — two lulls, cause undiagnosed.
  4. Class-distribution skew, cause resolved, residual isn't. Live predictions skewed toward II/Ib-c; dividing out the ELAsTiCC training prior moves Ib/c back into the real-rate band, confirming this is expected prior-mismatch behavior. A smaller residual (Ia still under, II still slightly over) remains unexplained — likely a calibration question, never directly checked.
  5. Smaller open items: fink-client installed (11.0) vs. locked (12.1.0); the SFD dustmaps mirror URL was never recorded; real_bogus_score didn't help but the experiment can't isolate why; WHXE was never re-tested against Tier B's non-SN-like population; the image encoder is cut, not deferred.
