## What was built

A multi-survey pipeline that classifies transient alerts into SN Ia / Ib-c
/ II from light curves plus host-galaxy features, pretrained on simulated
LSST data and fine-tuned on real ZTF data, served over a live alert stream
with an anomaly-ranking side branch and a results/monitoring UI.

- **`src/schema.py`** — the frozen `CanonicalAlert` contract every survey
  converts into (flux on one shared zeropoint, wavelength not band index,
  always-sorted observations).
- **Readers** (`src/readers/`) — ELAsTiCC2 (Tier A, pretraining), BTSbot
  (Tier B, real ZTF with spectroscopic labels, fine-tuning), and live Fink
  alerts for ZTF and LSST (Tier C, serving).
- **Model** — causal GRU light-curve encoder plus a static/host branch.
  **Deployed: LC+static**, fine-tuned on corrected Tier B
  (`outputs/finetune_bts_zpfix/with_static_{checkpoint.pt,model.onnx}`, seed 42).
- **Anomaly branch** — reconstruction-error decoder + Mahalanobis distance
  + isolation forest (PineForest), combined by z-score average; fitted
  scorers persisted and served.
- **Serving** — Kafka → Redis (rolling per-object state) → ONNX classifier
  + anomaly scorer → Postgres → FastAPI, in replay and live mode with the
  same consumer code.
- **UI** — Next.js dashboard (`frontend/`) plus the older single page (`ui/`).

## What the gates showed

- **Gate A (readers):** passed. Negative fluxes present in Tier A; real BTS
  class counts at a 13.8:1 Ia:Ib/c ratio, in line with the ~14.5:1 anchor.
  Gate A did not and could not catch the zeropoint inversion: Tier B
  fluxes were consistently mis-scaled and still looked like plausible
  light curves.
- **Gate B (causal model):** passed (shuffled labels, causality, ROC-AUC ceiling).
- **Gate C (fine-tune):** passed. A sim-to-real drop is present for both
  matched configurations.
- **Gate D (anomaly inspection):** **deferred, not failed.** Re-derived on
  corrected data (`reports/gate_d_zpfix_2026-11-06/`): the top 50 are 42
  CV/nova/LBV/LRN, 6 AGN, 1 91bg, 1 TDE, and 0 normal supernovae (pre-fix:
  46 / 3 / 1 / 0, also 0 normal); 35 of 50 objects are in both lists.
  Every one is a spectroscopically confirmed real object, because the only
  evaluation population is pre-filtered, so the gate's real question
  ("does real-bogus filtering suppress real signal") is still unasked.

## What was wrong, and what changed

**The zeropoint inversion.** `CLAUDE.md` §3 described converting nJy (AB zp
31.4) to FLUXCAL (zp 27.5) as multiplying by ~36.3; the correct operation
divides. The code and its unit test both encoded the document's version, so
all 414 tests passed while every real flux was wrong. A test asserting
magnitude invariance (a property, not the formula) failed 31 tests against
the old code. Consequences, now corrected:

1. **The "Tier B static-encoder inversion" is withdrawn.** Pre-fix, LC-only
   beat LC+static on Tier B (0.6716 vs 0.6343 as originally reported; 0.6754
   vs 0.6309 in the controlled 5-seed rerun on old fluxes). With correct
   fluxes the order reverses. It was the bug, not a finding.
2. **The deployed model changed** from LC-only to LC+static.
3. **Ib/c now misses its pre-registered band** (it was inside it on
   mis-scaled data). The band is not widened.
4. **The sim-to-real gap is reported between matched configurations.** The
   earlier "deployed gap" compared LC+static on Tier A with LC-only on
   Tier B.

## What remains unresolved

1. **Ib/c is weak on real data** (F1 0.2864 against a 0.40–0.60 band). With
   35 Ib/c test objects the number is noisy, and the band came from models
   with far more Ib/c support, but the miss stands.
2. **Output probabilities are not calibrated.** Live ZTF raw predictions
   are Ia 28.2 / Ib-c 3.9 / II 67.9 % (330 objects). A single
   multiplicative prior correction does not fit this model: dividing out
   the ELAsTiCC prior drives Ib/c to 0.3–0.6 %, and dividing out the
   effective Tier B fine-tune prior (Ia 56.8 / Ib-c 14.6 / II 28.6 %)
   drives II to 97 %. The Day-14 "prior mismatch explains the skew" result
   was for the pre-fix model and does not carry over.
3. **Large brightness shift between tiers.** Real BTS objects are ~36×
   brighter than the simulated training set. The fine-tune schedule was
   chosen while the bug hid most of that; a schedule designed for it has
   not been tried.
4. **Gate D's real question is still unasked** — it needs an unfiltered
   alert stream (or Fink's reject/candidate topics).
5. **LSST:** ingestion works on real traffic after the `decl` → `dec` fix,
   but there are no labels, so classifier accuracy on LSST is untested.
   LSST cutout stamps are 30–102 px and variable; the frozen schema's
   (3, 63, 63) shape cannot hold them, so LSST cutouts are not stored.
6. **Smaller open items:**
   - `fink-client` installed (11.0) — now matches `requirements-lock.txt`.
   - `real_bogus_score` as a Tier B input (DRB variant) still underperforms
     LC+static; the experiment cannot separate "uninformative feature" from
     "an extra branch overfits at this sample size".
   - WHXE was never revisited against Tier B's non-SN-like population.
   - The image encoder was cut (Day 12), not deferred.
