corresponding macro in numbers.tex; the relevant .tex section states the
gap in place of a number, per the paper spec's absolute rule on numbers.

Only CLAGN's mean max-softmax-probability (before/after span capping) survives, in reports/span_ablation/span_ablation_report.json. No JSON artifact stores them (confirmed: grepped reports/ and outputs/ for p50/p99/throughput, no hits), and GUIDE.md's own attempt to re-verify them this session failed (Postgres port occupied). No macro is defined for these numbers; Table 8 and the abstract say so explicitly rather than repeating the prose figures as if they were freshly verified.

- Majority-class and logistic-regression baseline rows (Table 6) were never run to completion or persisted anywhere on disk in this project -- src/eval/baselines.py exists but reports/ and outputs/ contain no baseline_report.json or equivalent. Producing one now would mean running a new baseline classifier fit, which the paper-writing brief's 'no retraining' rule was read to forbid (baseline fitting is a form of model training, not figure generation) -- see paper/NUMBERS_GAPS.md. Table 6 marks these rows as unavailable rather than fabricating a plausible baseline number.

- The Day-14 live-ZTF prior-correction analysis (raw vs. corrected class-distribution percentages, e.g. 'Ib/c 34.6% -> 13.9%') was computed once, live, against a Postgres query over that session's prediction rows, and was never persisted to a JSON file. It cannot be reproduced from any artifact in reports/ or outputs/ this session. The Discussion section describes the qualitative finding (training-prior leakage into output probabilities) without restating the specific percentages as disk-verified numbers.
